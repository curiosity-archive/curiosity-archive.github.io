# Curiosity Archive

Curiosity Archive is a personal, AI-assisted collection of stories about science, technology, history, and the world. 

The site is built with [Hugo](https://gohugo.io/) and the [Ananke](https://github.com/gohugo-ananke/ananke) theme. Its essays aim to explain how ideas and technologies developed, why particular choices mattered.
